9.1 📊 Tipi di Dati e Codifiche Visuali

data.dtypes
year             int64
country         object
cluster          int64
pop              int64
life_expect    float64
fertility      float64
dtype: object

La visualizzazione efficace dipende dalla comprensione dei tipi di dati in input, che guidano le possibili comparazioni e le appropriate codifiche visuali. Altair si basa su questi tipi per informare le scelte di design.

  1. Nominale (N): Dati categorici (es. paese). Supportano confronti di uguaglianza (A = B). Le codifiche adatte distinguono l’identità: posizione, colore (tonalità) e forma. L’uso della dimensione è fuorviante.

  2. Ordinale (O): Dati con un ordinamento specifico (es. anno se trattato come ordine). Supportano confronti di classifica (A < B). Le codifiche devono suggerire l’ordine: posizione, dimensione o valore del colore (luminosità).

  3. Quantitativo (Q): Dati numerici che misurano differenze:

    • Intervallo: Misura la distanza (A - B), come l’anno.
    • Rapporto (Ratio): Misura anche le proporzioni (A / B) grazie a uno zero significativo (es. fertilità). Si visualizzano con posizione, dimensione o valore del colore. L’asse zero è vitale per i dati di rapporto.

  4. Temporale (T): Caso speciale di dati quantitativi che misurano punti/intervalli di tempo (es. data).

Questi tipi formano una gerarchia: i quantitativi supportano l’ordine (ordinali), e gli ordinali l’uguaglianza (nominali). Il tipo di dato assegnato non è fisso e può essere modificato (es. trattare l’età come nominale o quantitativo) a seconda dell’analisi desiderata.

9.2 🌬️ Encoding Channels

Al cuore del funzionamento di Altair troviamo i canali di codifica. Questi vengono collegati a specifici attributi dei dati (ed il loro tipo) tramite codifica, in modo da ottenre il grafico che si vuole.

I principali sono i seguenti: - x: posizione orizzontale (asse x) del simbolo (mark). - y: posizione verticale (asse y) del simbolo (mark). - size: dimensione del mark; seconda del tipo di simbolo scelto puo corrispondere a lunghezzo o area. - color: colore del simbolo. - opacity: opacita del simbolo, da 0 (completamente trasparente) a 1 (completamente opaco). - shape: forma del simbolo differente. - tooltip: testo da mostrare quando il mouse passa sopra al simbolo. - column: allinea i dati orizzontalmente in sottografici. - row: allinea i dati verticalmente in sottografici.

# x
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q')
)
# y 
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q'),
    alt.Y('cluster:O')
)
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q')
)
# cambiare l'asse 
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q', scale=alt.Scale(zero=False)),
    alt.Y('life_expect:Q', scale=alt.Scale(zero=False))
)
# size 
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q'),
    alt.Size('pop:Q')
)
# fornire un range di dimensioni per il channel Size
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q'),
    alt.Size('pop:Q', scale = alt.Scale(range = [0,1000]))
)
# color 
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q'),
    alt.Size('pop:Q', scale=alt.Scale(range=[0,1000])),
    alt.Color('cluster:N')
)

# ordering: determina l'ordine in cui i dati sono disegnati sul grafico
alt.Chart(data2000).mark_point(filled=True).encode(
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q'),
    alt.Size('pop:Q', scale=alt.Scale(range=[0,1000])),
    alt.Color('cluster:N'),
    alt.OpacityValue(0.5),
    alt.Tooltip('country:N'),
    alt.Order('pop:Q', sort='descending')
)
# multiple tooltips 
alt.Chart(data2000).mark_point(filled=True).encode(
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q'),
    alt.Size('pop:Q', scale=alt.Scale(range=[0,1000])),
    alt.Color('cluster:N'),
    alt.OpacityValue(0.5),
    alt.Order('pop:Q', sort='descending'),
    tooltip = [
        alt.Tooltip('country:N'),
        alt.Tooltip('fertility:Q'),
        alt.Tooltip('life_expect:Q')
    ]   
)
# column and row encoding channels 
alt.Chart(data2000).mark_point(filled=True).encode(
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q'),
    alt.Size('pop:Q', scale=alt.Scale(range=[0,1000])),
    alt.Color('cluster:N'),
    alt.OpacityValue(0.5),
    alt.Tooltip('country:N'),
    alt.Order('pop:Q', sort='descending'),
    alt.Column('cluster:N')
)
# ridimensionamento dei grafici
# rimozione della legenda relativa al colore (informazione ridondante)
# spostamento in basso della legenda del canale size
alt.Chart(data2000).mark_point(filled=True).encode( # type: ignore
    alt.X('fertility:Q'),
    alt.Y('life_expect:Q'),
    alt.Size('pop:Q', scale=alt.Scale(range=[0,1000]),
             legend=alt.Legend(orient='bottom', titleOrient='left')),
    alt.Color('cluster:N', legend=None),
    alt.OpacityValue(0.5),
    alt.Tooltip('country:N'),
    alt.Order('pop:Q', sort='descending'),
    alt.Column('cluster:N')
).properties(width=135, height=135)

Infine diamo un’occhiata ad un’altra implementazione che permette di mostrare una barra di filtraggio dei dati interattiva. Questa tipologia di interazione interattiva con i dati sara esplorata in seguito, per il momento ci interessi solamente vedere quale sia il punto di arrivo di quello che stiamo facendo.

select_year = alt.selection_point(
    name='select', fields=['year'], init={'year': 1955},
    bind=alt.binding_range(min=1955, max=2005, step=5)
)

alt.Chart(data).mark_point(filled=True).encode(
    alt.X('fertility:Q', scale=alt.Scale(domain=[0,9])),
    alt.Y('life_expect:Q', scale=alt.Scale(domain=[0,90])),
    alt.Size('pop:Q', scale=alt.Scale(domain=[0, 1200000000], range=[0,1000])),
    alt.Color('cluster:N', legend=None),
    alt.OpacityValue(0.5),
    alt.Tooltip('country:N'),
    alt.Order('pop:Q', sort='descending')
).add_params(select_year).transform_filter(select_year)

9.3 🔤 Simboli (mark)

In Altair possiamo trovare diverse forme geometriche che possono essere utilizzate per visualizzare i dati:

  • mark_area() - area riempita definita da una linea superiore ed una inferiore.
  • mark_bar() - barre rettangolari.
  • mark_circle() - cerchi riempiti di uno Scatter plot points .
  • mark_line() - segmenti lineari connessi.
  • mark_point() - punti di uno Scatter plot con forme intercambiabili.
  • mark_rect() - rettangoli riempiti.
  • mark_rule() - linee orizzontali/verticali lungo gli assi.
  • mark_square() - quadrati riempiti di uno Scatter plot.
  • mark_text() - punti di uno Scatter plot rappresentati come testo.
  • mark_tick() - lineette orizzontali o verticali.
# point: scatter plot 
alt.Chart(data2000).mark_point().encode(
    alt.X('fertility:Q'),
    alt.Y('cluster:N'),
    alt.Shape('cluster:N')
)
# scatter plot with filled points 
alt.Chart(data2000).mark_point(filled=True, size=100).encode(
    alt.X('fertility:Q'),
    alt.Y('cluster:N'),
    alt.Shape('cluster:N')
)
# scatter plot con cerchi 
alt.Chart(data2000).mark_circle(size=100).encode(
    alt.X('fertility:Q'),
    alt.Y('cluster:N'),
    alt.Shape('cluster:N')
)
# scatter plot con quadrati
alt.Chart(data2000).mark_square(size=100).encode(
    alt.X('fertility:Q'),
    alt.Y('cluster:N'),
    alt.Shape('cluster:N')
)
# tick
alt.Chart(data2000).mark_tick().encode(
    alt.X('fertility:Q'),
    alt.Y('cluster:N'),
    alt.Shape('cluster:N')
)
# istogramma 
alt.Chart(data2000).mark_bar().encode(
    alt.X('country:N'),
    alt.Y('pop:Q')
)
# istogramma sovrapposto 
alt.Chart(data2000).mark_bar().encode(
    alt.X('cluster:N'),
    alt.Y('pop:Q'),  # ,stack = None),
    alt.Color('country:N', legend=None),
    alt.Tooltip('country:N')
)
# lifespan per cluster 
alt.Chart(data2000).mark_bar().encode(
    alt.X('min(life_expect):Q'), # starting point
    alt.X2('max(life_expect):Q'), # end point 
    alt.Y('cluster:N')
)
# line 
alt.Chart(data).mark_line().encode(
    alt.X('year:O'),
    alt.Y('fertility:Q'),
    alt.Color('country:N', legend=None),
    alt.Tooltip('country:N')
).properties(
    width=400
)
# cambiare i parametri base del mark line 
alt.Chart(data).mark_line(
    strokeWidth=3, # larghezza del tratto 
    opacity=0.5, # opacita 
    interpolate='monotone' # metodo di interpolazione dei punti
).encode(
    alt.X('year:O'),
    alt.Y('fertility:Q'),
    alt.Color('country:N', legend=None),
    alt.Tooltip('country:N')
).properties(
    width=400
)
# grafico di pendenza 

# intervalli temporali da confrontare 
dataTime = data.loc[(data['year'] == 1955) | (data['year'] == 2005)]

alt.Chart(dataTime).mark_line(opacity=0.5).encode(
    alt.X('year:O'),
    alt.Y('pop:Q'),
    alt.Color('country:N', legend=None),
    alt.Tooltip('country:N')
).properties(
    width={"step": 100} 
)
# area 
dataUS = data.loc[data['country'] == 'United States']

alt.Chart(dataUS).mark_area().encode(
    alt.X('year:O'),
    alt.Y('fertility:Q')
)
# area: interpolazione 
alt.Chart(dataUS).mark_area(interpolate='monotone').encode(
    alt.X('year:O'),
    alt.Y('fertility:Q')
)
# area: sovrapposizione 
dataNA = data.loc[
    (data['country'] == 'United States') |
    (data['country'] == 'Canada') |
    (data['country'] == 'Mexico')
]

alt.Chart(dataNA).mark_area().encode(
    alt.X('year:O'),
    alt.Y('pop:Q'),
    alt.Color('country:N')
)
# area: senza sovrapposizione 
alt.Chart(dataNA).mark_area(opacity=0.5).encode(
    alt.X('year:O'),
    alt.Y('pop:Q', stack=None),
    alt.Color('country:N')
)
# area: limite inferiore e superiore 
alt.Chart(dataNA).mark_area(color = 'red', opacity = 0.7).encode(
    alt.X('year:O'),
    alt.Y('min(fertility):Q'),
    alt.Y2('max(fertility):Q')
).properties(
    width={"step": 40}
)
